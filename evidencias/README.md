# Evidências da investigação INC-001

Esta pasta contém capturas de ecrã das consultas SQL
realizadas durante a investigação do incidente INC-001.

## Evidências disponíveis

| Evidência | Descrição |
|---|---|
| 01 — Diagnóstico inicial | Identificação da encomenda 1002 com pagamento aprovado e estado pendente |
| 02 — Validação dos valores | Verificação de divergências entre os valores das encomendas e pagamentos |
| 03 — Análise geral | Consulta com LEFT JOIN para analisar três encomendas |
| 04 — Análise das datas | Comparação das datas da encomenda e do pagamento |
| 05 — Consulta de logs | Análise cronológica de cinco eventos simulados |
| 06 — Identificação do erro | Identificação de um evento ERROR nos logs fictícios |
| 07 — Comparação de erros | Comparação de duas mensagens de erro simuladas |

## Nota importante

As evidências 01 a 04 apresentam consultas sobre
dados fictícios de encomendas e pagamentos.

As evidências 05 a 07 utilizam logs criados
artificialmente para fins de aprendizagem.

Os logs simulados não comprovam a causa raiz
do incidente original.
