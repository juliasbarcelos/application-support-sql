# Suporte Aplicacional | Investigação de Incidentes com SQL

## Sobre o Projeto

Este projeto apresenta uma simulação prática de
investigação de incidentes de suporte aplicacional
num ambiente fictício de comércio eletrónico.

O objetivo é demonstrar competências técnicas
de diagnóstico, análise de dados, resolução de
problemas e documentação de incidentes.

## Cenário

Uma encomenda permanece com o estado "Pendente",
apesar de o respetivo pagamento ter sido aprovado.

Esta inconsistência exige uma investigação para
identificar os registos afetados e determinar
as possíveis causas do problema.

## Objetivos

- Investigar inconsistências em bases de dados.
- Desenvolver e executar consultas SQL.
- Identificar e documentar incidentes aplicacionais.
- Analisar possíveis causas de falhas.
- Testar e validar uma proposta de correção.
- Elaborar um relatório técnico do incidente.

## Tecnologias e Ferramentas

- SQL
- SQLite
- Consultas e análise de bases de dados
- Técnicas de troubleshooting

## Estado do Projeto

Em desenvolvimento.

## Nota

Este é um projeto pessoal de aprendizagem,
desenvolvido com dados fictícios e num ambiente
simulado, sem ligação a sistemas de produção.
