# Relatórios de Incidentes

Esta pasta contém a documentação técnica dos incidentes investigados no projeto Application Support Portfolio.

## Incidente INC-001

**Descrição:** Encomenda 1002 pendente apesar de possuir um pagamento aprovado de 79,99 €.

**Estado do exercício:** Concluído.

**Estado do incidente:** Investigação encerrada sem resolução técnica. Causa raiz não determinada.

### Investigação realizada

- Identificação da inconsistência com SQL.
- Validação de valores e estados.
- Análise das datas registadas.
- Investigação complementar com logs fictícios.
- Comparação de mensagens de erro simuladas.
- Documentação das evidências e limitações.

## Nota

O projeto utiliza dados fictícios e foi desenvolvido para fins de aprendizagem.

Os logs simulados não representam evidências reais da causa raiz do incidente.
